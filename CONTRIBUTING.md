# 参与知刊 · Contributing

本仓库是 [知刊 / AILatest Journal](https://journal.ailatest.org) 的公开项目页。欢迎用中文或 English 讨论产品说明、文档和公开链接。

This repository is the public project page. Product notes, docs, and public links are welcome in Chinese or English.

## 适合放在这里

*In scope*

- 文档、截图说明、公开链接和 README 的更正。 Corrections to the docs, screenshot captions, public links, and README.
- 可复现的站点问题：页面、语言、浏览器，以及你看到的结果和期望。 Reproducible site issues, with the page, language, browser, and what you expected.
- 功能建议。 Feature suggestions.
- 期刊信息纠错。请附上可核验的公开来源（期刊官网、评价机构名录或正式通报），方便对照[关于与数据说明](https://journal.ailatest.org/about)。 Journal data corrections with a verifiable public source.

## 请不要提交

*Out of scope*

- 生产源代码、部署配置和密钥。 Production source, deploy config, and secrets.
- 受许可或受限的期刊数据集、名录打包文件、批量导出。 Licensed or restricted journal datasets, directory dumps, and bulk exports.
- 账号、支付记录和 API key。 Accounts, payment records, and API keys.
- 把某条影响因子、分区或预警写成永久事实的修改。截图和指标都会随公开版本更新，以线上页面和关于页的截止日期为准。 Edits that freeze an impact factor, zone, or warning as a permanent fact. Screenshots and metrics follow the public editions on the live site.

生产代码在私有仓库。Cloudflare 从那个仓库部署 [journal.ailatest.org](https://journal.ailatest.org)。

Production code lives in a private repository. Cloudflare deploys the live site from that source.

## 怎么反馈

*How to report*

打开 [Issues](https://github.com/stonecanon/ailatest-journal/issues)。标题写清页面或期刊标识（刊名或 ISSN 即可）。如果是数据纠错，请给出公开链接，而不是粘贴整份名录。

Open an [issue](https://github.com/stonecanon/ailatest-journal/issues). Name the page or the journal (title or ISSN). For a data correction, link a public source instead of pasting a directory.
