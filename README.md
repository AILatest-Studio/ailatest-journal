## 🌟 核心功能与亮点

- **检索全球与地区期刊**：按刊名、缩写、ISSN、学科、索引和开放获取筛选。覆盖 SCIE / SSCI / AHCI / ESCI、EI、Scopus、DOAJ、MEDLINE，以及中国、印度、韩国、马来西亚等地区目录。
- **对照分区、指标与风险**：查看 JCR 影响因子与 Quartile、中科院升级版分区（含 TOP 标记）、CCF / ABDC / ABS 等学科推荐等级，以及官方预警期刊名单。
- **同屏候选刊对比**：支持将多个目标期刊加入对比抽屉，一次性横向对比审稿周期、录用难度、版面费（APC）与历史预警记录，辅助精准选刊。
